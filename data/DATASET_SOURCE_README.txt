SQL Practice Pack — Automotive Product & Sales Data

Files:
- categories.csv
- suppliers.csv
- products.csv
- inventory.csv
- customers.csv
- orders.csv
- order_lines.csv
- schema.sql (MySQL 8+ table definitions)
- practice_questions.md (60 questions from beginner to advanced)

Recommended use:
1. Unzip the pack.
2. Run schema.sql in MySQL Workbench.
3. Import each CSV into its matching table using Table Data Import Wizard. If the wizard offers to create a new table, choose the existing table instead.
4. Start at Level 1 and work upward.
5. Save your answers in a .sql file as you go.

Important:
- Synthetic data only.
- CSVs are UTF-8 with headers.
- Prices are decimal amounts; currency is not specified.
- The order_lines discount_pct is stored as a fraction (e.g. 0.10 means 10%).
